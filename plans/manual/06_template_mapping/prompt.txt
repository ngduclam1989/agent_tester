Đây là bước cuối cùng. Hãy **chuẩn hóa format** toàn bộ các Test Cases đã sinh ở Bước 5 vào bảng Markdown chuẩn, phù hợp để copy/paste sang Excel hoặc import vào Jira/Zephyr/Xray/TestRail.

## Bảng chuẩn cần có các cột sau:

| TC ID | Module | Risk Level | Test Title | Pre-Condition | Test Steps | Expected Result | Priority | Test Data |

## Quy tắc khi lập bảng:

### TC ID
- Format thống nhất: `[DỰ_ÁN]_[MODULE]_TC_[SỐ]`
- Ví dụ: `CRM_CUST_TC_001`, `CRM_CUST_TC_002`...
- Tăng dần liên tục, không nhảy số

[Tùy chỉnh: Nếu bạn muốn quy tắc ID khác, thay thế format ở trên.
Ví dụ: `TC_LOGIN_001`, `TC_REG_001`...]

### Test Steps & Expected Result
- **PHẢI đánh số thứ tự** nếu có nhiều bước
- Sử dụng `<br>` hoặc danh sách `-` để xuống dòng trong cell Markdown
- Ví dụ trong cell:
  ```
  1. Mở trang Login<br>2. Nhập email: test@mail.com<br>3. Nhập password: Test@123<br>4. Click nút "Đăng nhập"
  ```

### Quy tắc TUYỆT ĐỐI:
- ❌ **KHÔNG ĐƯỢC** bỏ sót hoặc rút gọn bất kỳ Test Case nào đã sinh ở Bước 5
- ❌ **KHÔNG ĐƯỢC** tự ý gộp hoặc merge các Test Case khác nhau
- ✅ Nếu bảng quá dài → Chia thành **Part 1, Part 2, Part 3...** và hỏi tôi để tiếp tục

## Output & Chuyển đổi Excel (Bắt buộc)

1. Xuất kết quả dưới dạng **file Markdown** (`.md`) lưu tại thư mục tương ứng trong `practices/testcases/`.
2. Sử dụng skill `xlsx` để tự động hóa việc xuất bảng Test Cases ra file Excel `.xlsx` tương ứng:
   - Sử dụng phông chữ chuyên nghiệp, nhất quán (ví dụ: Arial, Times New Roman).
   - Áp dụng mã hóa màu sắc tiêu chuẩn ngành (xanh cho input dữ liệu thô, đen cho công thức).
   - Bảo toàn các bản mẫu định dạng Excel sẵn có của dự án.
3. Chạy công cụ xác thực để tính toán lại công thức và quét lỗi công thức Excel:
   ```bash
   python .agent/skills/xlsx/scripts/recalc.py <excel_file>
   ```
   Nếu phát hiện lỗi công thức (`#REF!`, `#DIV/0!`, `#VALUE!`), bạn bắt buộc phải sửa lỗi trước khi bàn giao file Excel hoàn chỉnh cho người dùng.

Nếu tổng số Test Cases > 30, hãy chia file thành nhiều phần hợp lý và hỏi tôi "Tiếp tục Part X?" trước khi sinh tiếp.
