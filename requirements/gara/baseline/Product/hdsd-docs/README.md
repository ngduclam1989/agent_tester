# hdsd-docs

## Mục đích

Lưu trữ các file tài liệu hướng dẫn sử dụng chức năng mới của phần mềm.

Tài liệu trong thư mục này dành để **đào tạo các đội ngũ nội bộ**:

- **BD (Business Development)** — đội phát triển kinh doanh
- **Sale** — đội bán hàng
- **CSKH (Chăm sóc khách hàng)** — đội hỗ trợ khách hàng

Mục tiêu: giúp các đội hiểu rõ chức năng mới để **hỗ trợ khách hàng cuối (end-user)** sử dụng phần mềm.

## Quy ước

- Mỗi chức năng/tính năng nên có một tài liệu hướng dẫn riêng.
- Tài liệu nên rõ ràng, dễ hiểu, có hình ảnh/ảnh chụp màn hình minh họa khi cần.
- Đặt tên file theo chức năng để dễ tra cứu.
