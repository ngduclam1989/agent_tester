## 2. Scope

### In Scope (Cross-boundary E2E flows)

- **Luồng chính Group + Product (Web)** — Tạo nhóm cha → tạo nhóm con → tạo mã trong nhóm con → gắn SKU → thêm ĐVT quy đổi → đính kèm → sửa → xóa
- **Cascade INACTIVE** Group — Sửa cha INACTIVE → con cascade → mã không dùng được phiếu mới (downstream W05)
- **Delete chain** Group — Xóa nhóm trống thành công; xóa nhóm có mã/con bị block
- **Delete Product** — Mã chưa giao dịch xóa thành công + cascade unmap SKU/conversion-unit/attachment; mã đã giao dịch xóa thất bại
- **Import end-to-end** — Tải template → file 100 dòng mix (95 valid + 5 invalid) → kiểm tra preview → xác nhận import → kiểm tra 95 mã mới + 5 dòng lỗi tải về
- **Export end-to-end** — Apply filter + export → download `.xlsx` → mở file kiểm tra 11 cột + đúng dữ liệu theo filter
- **Regression trên feature production hiện có dùng chung legacy `product`/SKU** — Procurement (`gf-purchase`) + Bán lẻ phụ tùng (`gf-sales`) không bị ảnh hưởng bởi schema/API mới của W03 (ADR-017 "zero break")
- **Cross-boundary auth propagation** — Web (token kế toán) → BFF → gf-inventory → gf-erp-mdm (master lookup) → tenant filter enforce
- **Permission test 2 role** — chủ garage + kế toán có thể thực hiện đầy đủ flow
- **TENANT-USERS enrichment** end-to-end — Tạo nhóm bởi user A → user B xem thấy tên user A trong audit
- **Race condition** — 2 user concurrent gắn cùng SKU
- **Cascade rollback atomicity** — cascade lỗi giữa chừng → rollback toàn bộ

### Out of Scope

- Unit test / integration test layer (thuộc TC-W03-API)
- Component-level UI test (thuộc TC-W03-UI / TC-W03-MOBILE-UI)
- Tenant isolation cross-tenant strict (thuộc TC-W03-ISOLATION.md)
- Performance / load test
- W04-W06 downstream (phiếu nhập/xuất, tồn kho, tính giá)
- **Cross-platform sync Web ↔ Mobile** (thuộc `TC-W03-MOBILE-E2E.md` — split file, giữ nguyên TC ID TC-W03-E2E-015/016/017/018)
