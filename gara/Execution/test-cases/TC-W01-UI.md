## 2. Scope

### In Scope

- Hiển thị / ẩn section theo màn hình & toggle Bảo hiểm (AC-0 Create ẩn, AC-1 Edit/Detail)
- 5 trường điều chỉnh: CK liên kết VT, CK liên kết CDV, Khấu hao vật tư (% per dòng), Giảm trừ bồi thường, Khấu trừ BH
- Toggle đơn vị VNĐ/% (Web dropdown, Mobile SegmentedButton) cho 3 trường hỗ trợ (AC-3/4/6)
- Validation field-level: âm, % > 100, biên, trống, trimspace, copy/paste, chữ
- Nút "Áp dụng tất cả" khấu hao đồng loạt + override per dòng (AC-8, EC-4)
- Panel "Tổng giá dịch vụ" read-only: Chi tiết theo bên / Phân bổ BH dấu+màu / Cân thanh toán (AC-9..12)
- Realtime preview BH/KH/Tổng (BR-INS-SO-ADJ-007, Web realtime + Mobile BLoC)
- Cảnh báo BH âm vẫn cho lưu (AC-12, EC-2)
- SO Detail read-only đúng giá trị đã lưu
- Form-level behavior: dirty guard, giữ data khi submit lỗi, nút Lưu state
- Currency/i18n VN, Accessibility, Mobile native (keyboard, back, orientation, offline)
- Toggle off BH=Có → BH=Không trên SO đã lưu allocation: cảnh báo + discard + reset, no stale data (cả web + mobile)
- Màn chi tiết phiếu QT BH: header + 3 nút hành động (AC-1, AC-12, AC-13), khối thông tin QT + KH/xe (AC-2, AC-3), 4 tab (AC-4..9), panel "Tổng giá dịch vụ" 3 phần, huỷ phiếu QT (AC-11), conditional display phiếu KH
- Mobile chi tiết phiếu QT: AppBar + 4 tab + panel + conditional display + nút Tạo hồ sơ disabled
- UI-Security: XSS field text, mask sensitive, permission/tenant UI, state matrix lỗi tải, a11y keyboard + i18n VN

### Out of Scope

- Persist / công thức server-side (xem file `TC-W01-API.md`)
- Luồng cross-boundary tạo phiếu QT BH từ góc nhìn user (xem file `TC-W01-E2E.md`)
- Khu vực thông tin BH baseline (toggle, dropdown CTBH, upload hồ sơ bảo lãnh — đã production)
- Cột Nguồn TT per line item (baseline production)
- Nội dung tạo/xem hồ sơ BH (FEAT-INS-DOSSIER-* — W02)
- Ghi nhận thanh toán (baseline production)
