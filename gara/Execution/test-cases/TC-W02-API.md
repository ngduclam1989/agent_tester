## 2. Scope

### In Scope

- **Phase A:**
  - FEAT-INS-STL-CREATE: Query màn Tạo phiếu QT trả block `insuranceAdjustment` read-only (breakdownByPayer + 5 khoản adjustments + settlementBalance)
  - CR-20260612-01: `GetSettlementDetail` tách per-payer — phiếu BH chỉ cột BH; phiếu KH từ SO có BH trả cờ `soHasInsurance` + block "Phân bổ BH" 3 khoản KH; ẩn 2 khoản CK liên kết BH
  - CR-20260612-02: gf-sales cung cấp giá trị "Bảo hiểm thanh toán" computed (warn-and-allow khi âm — cảnh báo BH < 0 nhưng API vẫn cho hoàn thành SO, không block)
  - CR-20260616-01: Template in phiếu QT — phiếu BH 5 khoản (−), phiếu KH từ SO có BH 3 khoản (+), SO không BH baseline
  - CR-20260616-02: agg-garage-graph trả giá trị từng khoản phân bổ tách BH/KH (render 2 cột)
- **Phase B:**
  - FEAT-INS-DOSSIER-CREATE: 6 endpoint canonical (POST tạo v1, POST versions, PUT documents/{docId}, POST export subset, GET versions, GET download signed URL)
  - FEAT-INS-DOSSIER-VIEW: Query list dossier versions + metadata file PDF
  - Upload validation: MIME whitelist, max 10MB/file, max 40MB/dossier
  - Signed URL TTL 300s enforcement
  - Optimistic lock (concurrent export)
  - Error codes: INS_DOSSIER_NO_DOC_SELECTED, INS_DOSSIER_DOCS_INCOMPLETE, INS_DOSSIER_VERSION_CONFLICT, INS_DOSSIER_PDF_GENERATION_FAILED, INS_DOSSIER_STORAGE_TIMEOUT

### Out of Scope

- Thay đổi công thức tính phân bổ BH (đã chốt W01 ADR-015)
- Re-generate PDF dossier cũ (PRINT-INS-005 bất biến)
- 2 khoản CK liên kết BH trên phiếu KH (đã chốt ẩn)
- Tích hợp realtime với DN BH
- Workflow phê duyệt nội bộ trước khi xuất hồ sơ
- Native camera capture (chỉ pick từ file system)
- Dashboard widget công nợ BH (W03)
- FEAT-INS-DASH-DEBT (deferred)
- GraphQL upload multipart (không có — file ở S3 qua uploadedFileUrl)
