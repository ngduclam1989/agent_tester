## 2. Scope

### In Scope

- **Sidebar navigation** — 3 tab: "Mã sản phẩm nội bộ" / "Nhóm vật tư hàng hóa" / "Kỳ kế toán" (kỳ kế toán = epic khác, chỉ kiểm tra tab tồn tại)
- **Material Group screens** (`/inventory/material-groups/...`):
  - `MaterialGroupListPage` — flat table render (KHÔNG tree), pagination, search box, filter status + parent, action column 3 icon
  - `MaterialGroupFormDialog` (create + edit unified modal) — 5 trường, validation client + server, cascade INACTIVE dialog xác nhận
  - Detail dialog read-only + audit info
  - Delete confirmation + block dialog ("Không thể xóa")
- **Internal Product screens** (`/inventory/internal-products/...`):
  - `InternalProductListPage` — flat table, search 3-col, filter status + nature + materialGroupId, 3 button toolbar (Thêm/Tải lên/Xuất file)
  - `InternalProductFormPage` (create + edit chia mode) — 4 section: Thông tin chung / SKU / ĐVT quy đổi / Đính kèm
  - `InternalProductDetailPage` — 3 tab dữ liệu + audit + 3 action button (Sửa/Gắn SKU/Thêm ĐVT)
  - Delete popup
- **Import wizard** (`/inventory/internal-products/import`) — 2 bước (Tải lên → Kiểm tra) + Kết quả + Tải file lỗi
- **Export single-call** — button click → `window.location.href = downloadUrl`, BFF reverse-proxy
- **Form validation** (client-side React Hook Form + zod):
  - Required field, regex code (ERR-INV-001/006), length (description ≤ 255 GRP / ≤ 500 PROD), enum nature 4 giá trị English label hardcode VN, conversionRate > 0 + scale ≤ 6
- **Empty state** — EC-11 (chưa có dữ liệu) + EC-12 (filter không khớp)
- **Error code rendering** theo display token (INLINE_FIELD / INLINE_FORM / DIALOG / TOAST)
- **Permission** — chủ garage + kế toán có quyền ngang nhau
- **Reuse-First** — kiểm tra không có component dựng mới (KG `web-component-registry.yaml` v3)
- **Testid coverage** — element interactive có `data-testid` (≥ 95% per PKG §3.C.1)
- **Bundle/code-split** — modules > 50KB qua React.lazy + Suspense

### Out of Scope

- API contract / GraphQL ops (thuộc `TC-W03-API.md`)
- Cross-platform sync Web ↔ Mobile (thuộc `TC-W03-MOBILE-E2E.md` nếu cần)
- Mobile UI (thuộc `TC-W03-MOBILE-UI.md`)
- Tenant isolation cross-tenant (thuộc `TC-W03-ISOLATION.md`)
- Performance / load test
- A11y screen reader nâng cao (chỉ kiểm tra keyboard nav + ARIA cơ bản)
- I18n (W03 hardcode tiếng Việt per G8)
