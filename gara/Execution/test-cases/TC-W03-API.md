## 2. Scope

### In Scope

- **Material Group (nhóm VTHH)** — 9 GraphQL ops (V2-Q1/Q2/Q3 + V2-M1/M2/M3) + 6 REST endpoint (V2-1..V2-6):
  - Search/list flat-grouped-by-parent ordering (R7)
  - Tree fetch + cap 1000 nodes defense (HTTP 413 + `ERR-INV-027`)
  - Create/edit/delete với cascade INACTIVE, kiểm tra vòng lặp, unique code per tenant, description ≤ 255
  - Delete guards: nhóm còn con (ERR-INV-005), nhóm có internal_product (ERR-INV-004)
- **Internal Product (mã sản phẩm nội bộ)** — 13 GraphQL ops (V2-Q4/Q5/Q7/Q8/Q9 + V2-M4..M13) + 13 REST endpoint (V2-7..V2-19, V2-22, V2-23):
  - Search keyword 3-col OR (code/name/SKU)
  - Detail enriched (mainUnitDisplayName, originDisplayName R18, materialGroupName)
  - Create với validation `nature` 4-enum English, `originCode` ISO 3166-1 alpha-3 (R18), `brand` free-text VARCHAR(255), `mainUnitCode` từ master, `initialConversionUnits[]` rate > 0 + scale ≤ 6 (ERR-INV-047)
  - Update với immutability matrix (code, mainUnitCode khi có transactions)
  - Delete guard: đã có giao dịch nhập/xuất/tồn (ERR-INV-008)
  - SKU mapping unique global (ERR-INV-015), unmap không xóa SKU gốc
  - Conversion-unit: rate > 0 (ERR-INV-013), scale ≤ 6 (ERR-INV-047), unique (ERR-INV-014), immutable sau giao dịch
  - Attachment: metadata-only, ≤ 5 file, ≤ 30MB (ERR-CMN-004), MIME PDF/JPG/PNG (ERR-CMN-005)
  - SKU search (V2-23, V2-Q8) với `unmapped=true`
  - listUnits (V2-Q9) gọi gf-erp-mdm `directory=UNIT`
- **Import (V2-20/21 + V2-M14/M15)**: verify-then-commit, cap 500 dòng (ERR-INV-041), per-row validation đầy đủ (ERR-INV-006/007/012/042/043/044), defaults `pricing_method=PWA` + `nature=GOODS`
- **Export (V2-22 + V2-Q7)**: R22 single-call reverse-proxy, 9 cột canonical, filename Vietnamese `danh-muc-ma-san-pham-noi-bo-{timestamp}.xlsx`, cap 1000 rows (ERR-INV-045)
- **Tenant isolation** — cross-tenant fetch trả `[]`/404
- **Auth header propagation** — Authorization, X-Tenant-Id, X-Branch-Id, x-request-id qua BFF
- **TENANT-USERS enrichment** (R20) — `createdByName`/`updatedByName` cho MaterialGroup

- **Hồi quy — tương thích ngược bảng `product` cũ (ADR-017)**: 5 endpoint cũ `/api/v2/products/*` (POST create, GET search, GET search-grouped, POST stock/cost-price, POST stock/total-by-skus) phải "không phá vỡ tính năng cũ" — không đổi schema/hành vi sau khi W03 triển khai các bảng mới (`internal_product`, `internal_product_sku_mapping`...) trong cùng boundary `gf-inventory`
- **CB-CAT-004 negative scope**: xác nhận `InternalProduct` KHÔNG áp dụng TENANT-USERS enrichment (`createdByName`/`updatedByName`) trong W03 — chỉ `MaterialGroup` mới có

### Out of Scope

- Phiếu nhập/xuất kho V2 (W05)
- Tồn kho / tồn đầu kỳ / tính giá (W04, W06)
- Báo cáo + UI design conformance (thuộc TC-W03-UI / TC-W03-MOBILE-UI)
- EP-CATALOG cũ (dịch vụ/NCC/nhà xe)
- Master data ĐVT / xuất xứ / SKU (thuộc gf-erp-mdm — pre-seeded)
- Multipart upload trực tiếp (W03 dùng presigned URL pattern ADR-016)
- Tenant isolation cross-tenant nâng cao (split sang TC-W03-ISOLATION.md)
- Performance / load test SLA (chưa có SLA target cho W03)
- **Downstream W04-W06** (EP-INVENTORY-RECEIPT-V2, DELIVERY-V2, STOCK-V2, OPENING-BALANCE, ACCOUNTING-PERIOD) — chưa được build (wave tương lai), không thể test integration với feature chưa tồn tại. Sẽ bổ sung khi các wave đó bắt đầu, kiểm tra consume `internal_product_id` đúng theo ADR-017 Risk note.
