## 2. Scope

### In Scope

**Phase A — FEAT-INS-STL-CREATE + 4 CR:**
- Mutation `createInsuranceSettlement` / `createSettlement` (agg-garage-graph #44/#47): additive payload snapshots `insuranceAdjustment` block (8 adjustment scalars + 16 breakdown scalars + `insurancePayableAmount`) vào phiếu QT BH
- Query `PrepareCreateSettlement` / `getServiceOrderByCode` (agg-garage-graph): trả block `insuranceAdjustment` gồm `breakdownByPayer` (4 dòng × 2 cột BH/KH), `adjustments` (5 khoản), `settlementBalance` (bhPayment / customerPayment / totalPayment)
- CR-20260612-01: `getSettlementByCode` tách per-payer — phiếu BH chỉ cột BH; phiếu KH từ SO có BH trả cờ `soHasInsurance=true` + block "Phân bổ BH" 3 khoản KH; ẩn 2 khoản CK liên kết BH
- CR-20260612-02: `gf-sales for-print /protected/v1/service-orders/{tenantId}/{code}/for-print` extend: `breakdownByPayer` 5 khoản per-payer (BH/KH values); warn-and-allow khi BH âm
- CR-20260616-01: Template in phiếu QT BH — section "Phân bổ bảo hiểm" 5 khoản dấu trừ; phiếu KH từ SO BH — 3 khoản dấu cộng; SO không BH giữ baseline
- CR-20260616-02: agg-garage-graph trả `bhValue`/`khValue` tách biệt per-adjustment cho FE 2-cột
- Validation server-side: INS_ADJ_MODE_INVALID (400, INS-1008 per CR-1781085632), INS_STL_COMPANY_REQUIRED (400, INS-2002), INS_STL_DUPLICATE_DRAFT (409, INS-2003), INS_STL_SO_NOT_COMPLETED (400, INS-2004)
- Error code contract (3 chiều): `code` symbol + HTTP status + side-effect per registry §3bis.9 gf-accounting-api v16
- Ground-truth DB assertion: sau createSettlement, SELECT `dev_gf_accounting.settlements` + `insurance_adjustment_lines` để verify snapshot khớp input

**Phase B — FEAT-INS-DOSSIER-CREATE:**
- BFF orchestrator 4-phase via `exportInsuranceDossier(settlementCode, documentTypes, acceptanceFormData?, authorizationFormData?)` (agg-garage-graph #51): resolve ctx → parallel render → upload ct-file-storage → atomic batch persist
- gf-accounting `POST /api/v1/insurance-dossier-documents/acceptance-record/render-pdf` (3bis.1): transient render ③ Biên bản nghiệm thu — 13 atomic formData fields, ~~400 INS_DOSSIER_FORM_INCOMPLETE~~ (**N/A per FEAT v22 — required-field gate gỡ; xem §3 WITHDRAWN note**), 404 INS_STL_NOT_FOUND
- gf-accounting `POST /api/v1/insurance-dossier-documents/payment-authorization/render-pdf` (3bis.2): transient render ④ Giấy ủy quyền — 23 atomic formData fields, ~~400 INS_DOSSIER_FORM_INCOMPLETE~~ (**N/A per FEAT v22**), 404 INS_STL_NOT_FOUND
- gf-accounting `POST /api/v1/insurance-dossier-documents/batch` (3bis.3): atomic persist INSERT dossier vN+1 + N doc rows + UPDATE vN→REPLACED; 400 INS_DOSSIER_NO_DOC_SELECTED, 409 INS_DOSSIER_VERSION_CONFLICT
- ct-file-storage `POST /api/v1/files/upload-files` multipart (BFF-called): MIME whitelist (pdf/jpeg/png), max 10MB/file
- Entry gate: chỉ từ phiếu QT BH (payerType=INSURANCE) — phiếu KH bị từ chối
- Export subset ≥1: `documentTypes` array tối thiểu 1 phần tử
- Optimistic locking (409 INS_DOSSIER_VERSION_CONFLICT) khi concurrent export
- Versioning: version_no auto-increment per settlementCode; cũ → REPLACED
- NO auto-save server: formData ③④ chỉ transient, KHÔNG persist DB
- Ground-truth DB assertion: sau batch persist, SELECT `insurance_dossiers` + `insurance_dossier_documents` verify rows đúng
- Per-field validation server: **[UPDATE 2026-06-24 — FEAT v22 gỡ EC-4/required-field gate: KHÔNG còn validate "bỏ trống" cho field nào của ③④ — case empty→400 đã WITHDRAWN. Chỉ còn validate format/value khi CÓ nhập giá trị]** format/value: `billDate` (dd/MM/yyyy), `customer.nationalId` (9/12 số), `customer.nationalIdIssueDate` (không tương lai), `compensation.amountNumeric` (không âm) — các field còn lại (`licensePlate`, `customer.name/address`, `garage.name/address`, `clauses[]`, `placeIssued`, `dateIssued`, `vehicle.licensePlate`) KHÔNG bắt buộc, để trống được

**Phase B — FEAT-INS-DOSSIER-VIEW:**
- `POST /api/v1/insurance-dossiers/search` (3bis.4): paginated list versions (Spring Pageable, max size=50), ordered desc `versionNo`; 404 INS_STL_NOT_FOUND; empty list 200 (không phải 404) khi chưa có hồ sơ
- `getInsuranceDossierVersions(settlementCode, page=0, size=10)` (agg-garage-graph #52): paginated list; schema validation; no signed URL TTL (ADR-016 v11 — pdfUrl là relative path, FE compose URL từ env)

- Immutability: không có DELETE endpoint; versions giữ vĩnh viễn (BR-INS-DOSSIER-VIEW-005)
- Pagination: page/size, boundary BVA (size=0 reject, size=50 accept, size=51 reject), page ngoài range trả empty

- Entry gate: phiếu KH (CUSTOMER) → reject (BR-INS-DOSSIER-011)
