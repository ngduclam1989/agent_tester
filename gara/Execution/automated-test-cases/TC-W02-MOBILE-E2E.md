## 2. Scope

### In Scope

- Journey-level E2E từ mobile native (Patrol live device/emulator) xuyên BFF `agg-garage-graph` → `gf-accounting` → `gf-sales` → DB + event + PDF storage.
- FEAT-INS-STL-CREATE: Tạo phiếu QT BH từ SO có BH — panel "Tổng giá dịch vụ" 2 cột, submit, end state đa-layer.
- FEAT-INS-DOSSIER-CREATE: Lập hồ sơ BH 4 tài liệu — điền Biên bản (form), điền GUQ (form), check 4 thẻ, Xuất hồ sơ PDF + file picker native.
- FEAT-INS-DOSSIER-VIEW: Xem tab "Hồ sơ đã xuất" — grid 2 cột PDF cards, tap PDF viewer, pull-to-refresh, versioning.
- Native interaction đặc trưng mobile: file picker PDF (C3), background-foreground lifecycle (C3), concurrent export 409 (C3).
- Regression journeys production mobile bị tác động bởi W02: SO complete flow (non-BH leak guard), share-PDF phiếu QT BH, panel 2 cột CR submit.
- Exception/timeout journeys bắt buộc: 5xx + retry, mạng mất mid-export, file type/size reject, background-foreground data loss, concurrent 409.

### Out of Scope

- UI golden pixel / wording isolated → `agent-test-mobile-ui`.
- API contract / schema validation exhaustive → `agent-test-api`.
- Cross-tenant denial (garage-a vs garage-b) → `agent-test-isolation`.
- Auth/authz abuse, OWASP → `agent-test-security`.
- SLO latency/throughput → `agent-test-performance`.
- Web journey counterpart (cùng business outcome trên garage-web) → `agent-test-e2e` (TC-W02-E2E).
- Camera capture (ảnh hư hỏng xe) — không áp dụng cho FEAT-INS-DOSSIER-CREATE (tài liệu dùng template điền + file picker PDF, không phải camera).
- Deeplink tới màn hồ sơ BH — chưa có deeplink scheme cho FEAT-INS-DOSSIER trong W02 (out-of-scope+lý do: feature không định nghĩa deeplink URL trong §4 API Reference).
- Push notification FCM cho hồ sơ BH — gf-notification không publish push event cho Dossier trong W02 (out-of-scope+lý do: FEAT-INS-DOSSIER-CREATE §4 không có event push).
- Biometric auth — out-of-scope cho W02 feature journey (không gate feature bằng biometric).
- Offline-to-online sync — FEAT-INS-DOSSIER-CREATE EC-1 chốt KHÔNG auto-save draft; offline action queue không applicable.
- App store install/update simulation — out-of-scope cho wave E2E business feature.
