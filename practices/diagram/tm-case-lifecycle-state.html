Vòng đời Case — Transaction Monitoring

Sơ đồ trạng thái hợp nhất từ 4 luồng nghiệp vụ trong BRD (tự động HIT kịch bản, thủ công DVKH, thủ công AML, re-open) — dùng làm căn cứ cho kỹ thuật State Transition Testing ở Bước 5 quy trình AI-RBT.

Sơ đồ có mật độ cao theo chủ đích — đây là tài liệu tham chiếu kỹ thuật cho State Transition Testing (Bước 5 AI-RBT), không phải diagram trình bày cấp điều hành, nên ưu tiên đầy đủ transition hơn tối giản hình ảnh.

Ghi chú kỹ thuật

"Pending Maker" là 2 điểm resume khác nhau

  • Return từ Pending Checker Review → Add Info → quay lại chính nó (resume Bước 2/Recommend).
  • Return từ Pending Checker Review STR / Pending Supervisor Review → Add Info → quay lại Pending Checker Review STR (resume Bước 4/tạo lại STR) — không quay lại Bước 2.
  • Return từ nhánh AML (Pending AML Checker review) đi tới trạng thái Pending AML Maker riêng, không dùng chung hub "Pending Maker".
