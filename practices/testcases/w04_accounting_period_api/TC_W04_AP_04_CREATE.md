# W04 Accounting Period API - Create

- API: `POST /api/v2/accounting-periods`
- Source: `gara/Architecture/api/gf-accounting-api.md` section 4.4; `gara/Execution/wave-specs/W04/Product/features/be/FEAT-AP-CREATE.md`; `gara/Execution/wave-specs/W04/Product/business-rules/BR-GF-INVENTORY-ACCOUNTING-PERIOD.md`
- Scope: kiểm tra tạo kỳ kế toán YEAR/QUARTER/MONTH, hierarchy, date range, overlap, auto-generate children, validation và tenant isolation.
- Assumption đã chốt: API không block tạo kỳ quá khứ nếu `year` khớp với `startDate.year`; lỗi blank `name` dùng common validation.

## Luồng API cần kiểm thử

1. Client gửi JWT user có quyền tạo AP và body create.
2. BE resolve tenant, validate required fields và enum.
3. BE validate hierarchy theo `type` + `parentId`, date range, `year`, overlap sibling.
4. Nếu `autoGenerateChildren=true`, BE sinh children trong cùng transaction.
5. BE persist AP, trả 201; nếu bất kỳ validation/auto-generate lỗi thì rollback toàn bộ.

## Validate dữ liệu API

| Trường/Header | Rule cần kiểm tra | TC phủ |
|---|---|---|
| `Authorization` | Bắt buộc JWT user được phép mutate AP | `GARA_AP_CREATE_TC_018`, `GARA_AP_CREATE_TC_023`, `GARA_AP_CREATE_TC_025` |
| `X-Tenant-Id` / tenant context | Parent lookup và overlap check phải scope tenant hiện tại | `GARA_AP_CREATE_TC_003`, `GARA_AP_CREATE_TC_004`, `GARA_AP_CREATE_TC_012`, `GARA_AP_CREATE_TC_026` |
| `name` | Required, non-null/non-blank, max 255; không bắt unique | `GARA_AP_CREATE_TC_005`, `GARA_AP_CREATE_TC_020` |
| `type` | Required enum `YEAR`, `QUARTER`, `MONTH` | `GARA_AP_CREATE_TC_006` |
| `parentId` | `YEAR` bắt buộc null; `QUARTER` parent phải là YEAR; `MONTH` parent phải là QUARTER; parent cùng tenant | `GARA_AP_CREATE_TC_007`, `GARA_AP_CREATE_TC_008`, `GARA_AP_CREATE_TC_009`, `GARA_AP_CREATE_TC_011` |
| `year` | Required; phải khớp `startDate.year`; QUARTER/MONTH phải khớp parent year | `GARA_AP_CREATE_TC_013`, `GARA_AP_CREATE_TC_019` |
| `startDate` / `endDate` | Required ISO date; `endDate >= startDate`; child range phải nằm trong parent range | `GARA_AP_CREATE_TC_010`, `GARA_AP_CREATE_TC_011` |
| Sibling overlap | Không được overlap date range với sibling cùng parent | `GARA_AP_CREATE_TC_012`, `GARA_AP_CREATE_TC_017` |
| `status` | Optional enum `OPEN`, `CLOSED`; default `OPEN` | `GARA_AP_CREATE_TC_002`, `GARA_AP_CREATE_TC_022` |
| `displayOrder` | Optional integer; default `0` | `GARA_AP_CREATE_TC_001`, `GARA_AP_CREATE_TC_002` |
| `description` | Optional, max 500 chars | `GARA_AP_CREATE_TC_001`, `GARA_AP_CREATE_TC_021` |
| `autoGenerateChildren` | Optional boolean; chỉ hợp lệ cho `YEAR`/`QUARTER`; atomic create + generate | `GARA_AP_CREATE_TC_015`, `GARA_AP_CREATE_TC_016`, `GARA_AP_CREATE_TC_024` |
