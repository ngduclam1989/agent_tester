[5] FILE CẤU HÌNH BẮT BUỘC TỰ TẠO — .env
--------------------------------------------------------------------------------
 File .env nằm trong .gitignore nên KHÔNG theo repo. Sang máy mới phải tạo lại:

     cp .env.example .env      (Windows PowerShell: Copy-Item .env.example .env)

 Rồi điền giá trị thật. Các biến hiện đang được code đọc:

     API_BASE_URL        Bắt buộc — base URL của API sản phẩm (suite product-add)
     API_LOGIN_PATH      Tuỳ chọn — mặc định /login-with-local
     API_USERNAME        Bắt buộc — tài khoản login lấy Bearer token
     API_PASSWORD        Bắt buộc
     API_LANG            Tuỳ chọn — mặc định VN

     AML_BASE_URL        Bắt buộc — base URL API AML Transaction Screening
     AML_USERNAME        Bắt buộc — tài khoản Basic Auth
     AML_PASSWORD        Bắt buộc
     AML_AUTH_HEADER     Tuỳ chọn — dán thẳng chuỗi "Basic xxx"; có giá trị thì
                         ghi đè AML_USERNAME/AML_PASSWORD

 Thiếu biến bắt buộc thì test dừng ngay với thông báo rõ tên biến còn thiếu
 (xem config/env.ts -> hàm required()).


[6] CÁC BƯỚC CÀI ĐẶT TỪ ĐẦU
--------------------------------------------------------------------------------
 1. Cài Node.js LTS (>= 18)
 2. cd TestScript
 3. npm install                     # cài toàn bộ thư viện ở mục [2] và [3]
 4. cp .env.example .env            # rồi điền giá trị thật
 5. npx playwright install chromium # CHỈ khi cần chạy test web
 6. Chạy thử:  npm run test:api


[7] LỆNH CHẠY (định nghĩa tại package.json -> scripts)
--------------------------------------------------------------------------------
 npm run test               Chạy toàn bộ test (cả api và web)
 npm run test:api           Chạy toàn bộ suite API
 npm run test:aml           Chạy riêng suite AML Transaction Screening
 npm run test:api:ui        Chạy suite API ở chế độ UI mode của Playwright
 npm run test:api:allure    Chạy suite API kèm ghi kết quả cho Allure
 npm run test:web           Chạy suite Web ở chế độ headed (có hiện trình duyệt)
 npm run report             Mở báo cáo monocart (test-results/report.html)
 npm run clean              Xoá test-results, allure-results, allure-report

 LƯU Ý: KHÔNG dùng `npx playwright show-report` — lệnh đó chỉ mở reporter 'html'
 của Playwright, mà project này không bật 'html' nên sẽ không có gì để mở.
